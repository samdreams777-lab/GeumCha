## Image SEO

### Filename Convention
```
{category}-{dish-name}.webp
{category}-{ingredient-group}.webp
hero-{viewport}.webp
og-default.webp
```

Examples:
- `ramen-kimchi-octopus.webp`
- `hotpot-seafood-large.webp`
- `ingredients-fresh-beef.webp`
- `hero-desktop.webp`

### Alt Text Strategy
- **Menu items**: "{Vietnamese name} — {short description}, Seoul Korean Cuisine"
- **Ingredients**: "Fresh {ingredient} for Korean cooking at Seoul Korean Cuisine"
- **Hero**: "Seoul Korean Cuisine — {main dish} served on black ceramic bowl, dark stone table"
- **Decorative**: Empty `alt=""` with `role="presentation"`

### Technical
- `width`/`height` attributes on all `<img>`
- `srcset` with 400w, 800w, 1200w
- `sizes` per layout context
- `loading="lazy"` (except hero)
- `decoding="async"`
- WebP primary, AVIF via `<picture>` for supporting browsers
